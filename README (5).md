### Hi, I'm Sahil 👋

I run **[Zaini Developers](https://zainidevelopers.com)**, a software studio working across the **UAE and India**. We build business software that companies run on every day: ERPs, POS systems, CRMs and SaaS platforms.

Right now I'm working on **UAE e-invoicing**, which becomes mandatory in 2027, and open-sourcing the hard parts so other developers don't have to start from zero.

### 🏗️ What I build

- **FORMA**: a white-label, multi-tenant ERP with UAE e-invoicing built in
- **ZainiPOS**: point of sale for web and mobile (Flutter) with a SaaS admin panel
- **ZainiPrint**: QR scan-to-print SaaS for print shops
- **StaffManager Pro**: HR and payroll management
- Custom CRMs and websites for clients in the UAE and India
